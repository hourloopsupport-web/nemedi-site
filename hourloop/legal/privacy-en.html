Privacy Policy — Hourloop

Last updated: 4 October 2026
Русский English

This policy explains what data is processed in the mobile game Hourloop (the "Game"), by whom and for what purpose. The Game is distributed through Huawei AppGallery and RuStore.

Developer: NeMedi
Studio Contact: nemedistudio@gmail.com
Game Support: hourloop.support@gmail.com

1. In short

The Game requires no registration and never asks for your name, email, phone number or payment details. Run history and settings are stored on your device only; meta progression (regular gold, talents, abilities, Game+, Clock Tower weekly record, module merge escrow) is additionally copied to an account cloud save on the game server. Chronites, keys, and banner items are also stored on the game server and linked to a randomly generated player ID rather than to an individual or a device, to protect balances and items from tampering. Optionally, you can link a VK ID or email address to your account to transfer your progress, chronites, keys, and items to another phone (linking is entirely voluntary; without it the Game works as before).

Four kinds of data leave your device, and none of them identifies you personally:

  • data of the game server wallet, banner, Clock Tower, and cloud save (section 4): chronite and key balances, items obtained, run sessions, pull history, and the meta progress cloud save, linked to a random player ID. In the weekly tower leaderboard, other players see a generated name, floor, and time, never your player ID;
  • account linking data, if you linked an account (section 4): your VK user ID or email address for logging into the same account on another phone;
  • data collected by advertising networks in order to serve ads (section 5). Ads are shown only when you tap the rewarded-video button;
  • anonymous gameplay statistics the Game sends to the AppMetrica analytics service (section 6): how far players get, where they lose most often, which upgrades they pick. This data is used to tune difficulty and balance.

4. Game server (chronites, keys, items, and Clock Tower)

In Game versions featuring the banner, chronites, Game+ tiers, and Clock Tower mechanics, the Game communicates with its own server to protect high-value in-game assets against tampering and to power the weekly leaderboard.

What is stored on the server:

  • Wallet: randomly generated player ID, access token, random installation token, chronite and key balances, lifetime earned/spent counters, creation timestamp;
  • Account links (auth_links): sign-in method (VK ID or email), VK user ID or email address, player ID, link timestamp;
  • Confirmation codes (auth_codes): neither address nor code is stored, only their cryptographic hashes (HMAC); code expiry time, remaining attempts, timestamp and daily sent email count — to protect against brute-force and spam abuse;
  • Cloud save (saves): a copy of meta progression (regular gold, talents, abilities, Game+, Clock Tower weekly record, module merge escrow). Stored alongside the save are: save version number, server recording timestamp and phone clock save timestamp, payload size, and a random save key (no device identifier is transmitted by the client). Purpose: to transfer progress to another phone upon signing into a linked account and prevent data loss; the server does not interpret the payload contents nor credit anything based on it. Run history is not uploaded to the cloud and remains on the phone. The save is uploaded to the server no more than once per minute and when the game is minimized;
  • Transaction ledger: each credit and debit record (for completing an act or watching an ad, buying keys, performing gacha pulls, reaching Clock Tower milestones 10 / 20 / 30 / 40, or first-time clearance of a Game+ tier), amount and timestamp;
  • Campaign run sessions: random run session ID, last submitted act number and timestamp — used to prevent duplicate reward claims;
  • Clock Tower runs (endless_runs): random run token, week ID, start and completion timestamps according to server time, floor reached, duration, and an implausible-result flag. Start and completion times are recorded by the server to filter out implausibly fast runs: such runs are not counted and do not enter the leaderboard;
  • Weekly best results (endless_best): the player's best record for each week (floor reached, duration, run token, recorded timestamp). Records of past weeks are not automatically erased when a new week begins;
  • Banner guarantees (pity): pull counters used to calculate guaranteed high-rarity drops;
  • Item inventory: awarded equipment items and their rolled stats;
  • Pull history: records of items obtained and pull timestamps.

Clock Tower weekly leaderboard. Players can view the public weekly leaderboard, showing the top 100 results of the week and your own entry. Each entry contains a generated name, floor reached, completion time, and rank. Your player ID (user_id) and any other details about you are never sent to the leaderboard and are not visible to other players. Player names are not stored in the database: the server computes them on the fly from your player ID using cryptographic hashing (HMAC) in a format such as "Brass Pendulum #4821". It is impossible to recover your player ID from this name. Custom names cannot be entered.

What the server does NOT store: your name, surname, phone number, advertising identifier (GAID/OAID), permanent device identifier (Android ID), device model, or IP address. The server retains your email address only if you voluntarily linked it to your account. From VK, the server retains strictly the VK user ID: access tokens, name, photo, phone number, and other profile details are never requested or stored. Server functions do not log player IP addresses; the cloud hosting infrastructure may observe connection metadata solely during active network transmission, and the Game does not retain it.

Account linking and logging in on another device. Linking an account to a VK ID or email address is voluntary and configured in "Settings" → "Account". Logging in via VK ID on Android uses the official VK ID SDK (via the installed VK app or browser): the server receives a one-time code, exchanges it, and stores only the VK user ID (without access tokens, name, or contacts). To link an email, a 6-digit confirmation code is sent to the specified address (valid for 15 minutes, up to 5 attempts, at most 1 email per minute and 10 per day per address; sent via Yandex Cloud Postbox from noreply@nemedistudio.online, containing only the code and its expiration time). In the confirmation codes database, neither the address nor the code is saved — only their cryptographic HMAC hashes are kept. In the game itself, the email is masked as p***@mail.ru. When logging into a linked account on another phone, that account's progress is transferred there from the cloud save (replacing whatever progress was on that phone). The server issues a new access token, while the previous phone loses access to this account and starts over as a clean guest: progress on it is erased, remaining safely stored in the account's cloud save on the server. On the account deletion page, signing in with VK ID is performed via a redirect to id.vk.ru (VK ID web application, VK LLC); there are no third-party VK scripts on our pages. The server exchanges the code and locates the linked account by the VK user ID to delete it. An email code for deletion is requested under the same limits, and the email message explicitly states that the code confirms account deletion. The deletion process retains no new data.

Where data is hosted: the server is hosted on Yandex Cloud (Russia), processing data solely on behalf of the developer as an infrastructure provider.

Offline operation: without an active internet connection, no data is transmitted to the server, operations are queued locally on the device, and chronites or pulls are not processed until connectivity is restored.

5. Advertising

The Game uses:

  • Yandex Mobile Ads — in all versions of the Game;
  • Petal Ads (Huawei Ads) — in the Huawei AppGallery version only;
  • VK Ads (formerly myTarget) — in the RuStore version only. It is connected through Yandex Mobile Ads mediation: the request goes to Yandex, which then decides whether to serve its own ad or pass the impression to VK Ads.

To select and deliver ads, and to prevent fraud, these networks may process:

  • the device advertising identifier (GAID on devices with Google services, OAID on Huawei devices) — a non-permanent identifier you can reset or limit in your device settings;
  • technical device information: model, OS version, language, region, connection type, screen resolution;
  • IP address;
  • ad delivery data: which ads were shown, whether they were watched to the end, whether they were clicked. The Yandex ad SDK reports such technical ad events to the AppMetrica analytics service (owned by Yandex) — this is part of how the ad network itself works. For the gameplay statistics the Game sends there on its own, see section 6.

The Game's developer does not receive this data and has no access to it — it goes directly to the advertising networks and is processed under their own terms; links are in section 7.

Ad personalisation is your choice. On first launch the Game asks whether the advertising networks may use your device advertising identifier to pick more relevant ads:

  • if you agree — the networks may use that data to select ads;
  • if you decline — every network is told to disable personalisation, and you see non-personalised ads;
  • until you answer — the decline setting applies.

You can change your mind at any time: Settings → the relevant-ads toggle. The networks are also given a content rating: the Game carries a 12+ rating (China 12+, Brazil A14, other regions 12+), and ads unsuitable for that age should not be shown.

6. Gameplay statistics (AppMetrica)

The Game sends anonymous gameplay statistics to the AppMetrica analytics service (owned by Yandex). This data is used to tune difficulty and balance, and to assess the effectiveness of advertising campaigns.

What the service collects on its own, without the Game's involvement:

  • the fact that the Game was installed, and which ad you came from if you arrived through advertising;
  • app launches, their duration and frequency;
  • technical information: device model, OS version, Game version, language, and approximate country and region derived from your IP address;
  • crash data: technical information about where the Game terminated with an error.

What the Game sends as its own events:

  • start and end of a run: game mode (campaign or Clock Tower), outcome, act reached, room number, floors cleared (in tower), duration, in-game currency earned;
  • entering and completing a room: game mode, tower floor number, room type, act number, health remaining, time elapsed;
  • defeat: the act, room and wave where it happened;
  • defeating an act boss;
  • picking one card out of three: the options offered and the choice made — for Parts, room rewards and permanent Legacy bonuses;
  • purchasing a node in the talent tree;
  • watching a rewarded video ad.

The statistics do not contain your name, email, phone number, any text you have typed, the contents of your device, or data about your location: location collection is disabled in the Game. Country and region are approximated by the service from your IP address.

Your device advertising identifier (GAID / OAID) is passed to AppMetrica only if you agreed to ad personalisation (see section 5). If you declined or have not answered, the identifier is not passed.

The developer has access to this data in the form of reports. It cannot be tied to a particular person: the Game holds no information identifying you.

8. How long data is kept

  • On your device — until you reset progress in Settings or uninstall the Game. No automatic retention periods apply.
  • On the game server — wallet data, account links (auth_links), cloud saves (saves), inventory, pull history, Clock Tower runs, and weekly best records are retained until the account is deleted (in the game, on the account deletion page, or upon request to support; account links and cloud saves are kept as long as the account exists). One-time confirmation code records (auth_codes) are overwritten by subsequent requests and do not contain email addresses. Your entries in past weekly leaderboards remain (name, floor, time) until account deletion. Please note: "Reset Progress" in Settings zeroes out progress on the phone, and the next upload overwrites the cloud save on the server with an empty one; chronites, keys, items, and account links on the server remain intact. Uninstalling the Game removes only local files and does not delete data from the server. Reinstalling the Game creates a new separate wallet with a new random ID, leaving the old one inaccessible (unless the account was linked to a VK ID or email). Deletion methods are listed in section 9.
  • By the advertising networks and AppMetrica — for the periods set by their own policies (links in section 7). The developer does not control those periods.

9. Your rights and how to exercise them

  • Change your ad personalisation decision: Settings → the relevant-ads toggle. It takes effect immediately and is passed to every network, AppMetrica included.
  • Reset your advertising identifier: in your device settings, under privacy or ads. After a reset neither the ad networks nor the analytics recognise you any more.
  • Delete data from your device: Settings → reset progress zeroes out progress on the phone (run history is permanently erased), and the next upload overwrites the cloud save on the server with an empty one (chronites, keys, items, and account links remain on the server). Uninstalling the app removes every file listed in section 3.
  • Delete data from the game server: three methods are provided: 1) in the game immediately — "Settings" → "Account" → "Delete account" → "Delete forever" (works for any account, including unlinked guest profiles; erases both server data, including cloud saves, and progress on this phone immediately); 2) on the account deletion page for linked accounts immediately — via VK ID sign-in or email confirmation code; 3) by email to support with Player ID within 30 days — send an email to hourloop.support@gmail.com with the subject "Account deletion" and provide your Player ID (find your ID in the game: Shop tab → History subtab; if you linked an email, you may write from that email without specifying the Player ID). Deletion via the website or by email erases data on the server; the game on your phone learns of this upon its next server request and erases progress on the phone, starting over as a clean guest. Server deletion permanently erases the wallet, VK ID and email links, email confirmation codes (auth_codes), cloud saves (saves), transaction ledger, run sessions, guarantee counters, pull history, items, Clock Tower runs, and leaderboard records. Detailed instructions and the deletion form are available on the account deletion page.
  • Ask a question or submit a request about data processing: write to the address in section 12.
  • Contact the recipients directly: rights regarding data processed by Yandex, Huawei and VK are exercised through them; the procedure is described in their policies, linked in section 7.

10. Children

The Game is not specifically directed to children: it targets a general audience and carries an official age rating of 12+ based on its content, not on its intended audience. It collects no personally identifying information. The "child-directed app" flag is not sent to the advertising networks; the 12+ content rating is sent instead (section 5).
